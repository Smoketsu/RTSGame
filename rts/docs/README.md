# Project documentation

- [STATUS.md](STATUS.md): **start here.** Which branch is current, which phases are done, what is being built now and what comes next.
- [PHASE1_PLAN.md](PHASE1_PLAN.md) and [PHASE2_PLAN.md](PHASE2_PLAN.md): build order, ownership and exit test for each phase.
- [decisions/](decisions/README.md): architecture decision records, ADR-001 to ADR-009. An accepted record is not edited; a later record supersedes it.
- [specs/](specs/README.md): implementation specs with acceptance tests, written before each system is built.
- [proposals/](proposals/README.md): proposals awaiting or recording a developer decision (P-001 art pipeline, P-002 community and store, P-003 decisions still to apply).
- [art/CONCEPT_BRIEF.md](art/CONCEPT_BRIEF.md): art direction and the table of approved concept art; `art/concept/` holds every round, `art/models/` the 3D generation trials.
- [CHANGELOG.md](CHANGELOG.md): every change, grouped by version and phase, in Keep a Changelog format.
- [ASSET_STORE.md](ASSET_STORE.md): shortlist of Unity Asset Store packages for presentation only.
- [UNITY_SETUP.md](UNITY_SETUP.md): how to open and set up the Unity 6 project, and the Unity-versus-headless hash check.
- [CI.md](CI.md): what the continuous integration workflows run.
