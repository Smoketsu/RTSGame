# Statuses (Phase 1 placeholder)

Not built yet. Phase 1 (Prototype, Skai vs water, Jan-Mar 2027) adds the shared status system here.

- Grounded: a flyer is brought to the ground layer for the status duration.
- Slowed: reduces a unit's movement speed for the status duration.
- Any faction can apply and receive these statuses; no status belongs to one faction.

Durations and values are data in `rts/data/tuning/statuses.json`.
