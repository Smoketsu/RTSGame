# Earth faction (Phase 4 placeholder)

Not built yet. Phase 4 (Earth update) adds the Earth faction mechanics here, as an `IFactionMechanic` plug-in.

- Tailoring, including Recasting: Recasting takes 15 s, for 25% of cost.
- Attunement: +1% per hit, capped at 30%, fading by 5% every 10 s.

Values are data in `rts/data/tuning/earth.json`. The core never names this faction; it is registered by ID.
